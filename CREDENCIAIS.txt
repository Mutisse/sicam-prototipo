NOTAS
------------------------------------------------------------

1. Se escreveres um e-mail que NÃO corresponde a nenhum
   perfil (ex: joao@sicam.gov.mz), o sistema entra como
   ADMIN por defeito.

2. O perfil válido é detectado pela parte antes do @:
      admin@...    → admin
      chefe@...    → chefe
      inatro@...   → inatro
      gestmul@...  → gestmul
      issm@...     → issm
      prm@...      → prm
      agente@...   → agente
      cidadao@...  → cidadao

3. Quando o backend estiver ligado (http://127.0.0.1:8000),
   estas credenciais serão substituídas por autenticação real.
